# Othello

Two-player Othello you host on your own computer. No dependencies, just Node.js.

```sh
npm start
```

The server prints the addresses to open. Your friend uses the `http://192.168…:3000` one while on the same Wi-Fi. Each of you clicks Sit on a color. To play on one screen, sit in both seats.

Set `PORT` to use a different port. Run the rules tests with `npm test`.
